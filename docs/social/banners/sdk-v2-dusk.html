@arcveil/sdk

A mandate goes on Arc. Your keys never do.

Publish the mandateOnly its commitment is registered. The terms stay with you.
Issue a receipt per actionProof it stayed in bounds. No amounts, no balances.
Anyone verifiesFive checks against Arc mainnet.
$ pnpm add @arcveil/sdk viem

// only the commitment reaches the chain
const terms = "assets: USDC only\nper action: 250 USDC"
const commitment = mandateCommitment(terms)
await registerMandate({ client, registry }, 1, commitment)

// one receipt per action, no amounts inside
const { receipt, issuer: next } = await issuer.issue({
  kind: "swap", userOpHash, settledTx })
